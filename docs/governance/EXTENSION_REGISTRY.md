# TRUYN Extension Registry

This registry records project-governed Experimental, Official and Core Candidate extensions.

Community Extensions in third-party namespaces are permissionless and are not required to appear here.

## Registry rules

- entries must correspond to an actual governance decision;
- Experimental entries must link their draft specification and sponsor;
- Official entries must link specification, implementation/conformance evidence and approval decision;
- Core Candidate entries must link adoption/independent-implementation evidence;
- promotion to Core is recorded in the normative protocol history through a separate RFC, not merely by editing this table;
- external standards such as A2A, MCP, x402 or AP2 are not automatically TRUYN extensions/core merely because adapters support them.

# TRUYN/1 Claim

**Status:** draft normative skeleton.

A `CLAIM` is a signed assertion about a subject/predicate/value in a domain and time context.

Claims SHOULD carry or reference:

- source identity;
- observation/effective time and expiry/freshness horizon;
- domain;
- provenance lineage;
- evidence objects;
- canonical value representation;
- signature.

A valid signature establishes attribution/integrity, not factual truth. Trustability is computed separately.

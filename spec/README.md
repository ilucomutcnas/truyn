# TRUYN Specifications

Normative network contracts live here. Protocol generations are versioned independently from software releases.

- `protocol/v1/` — draft TRUYN/1 semantics.
- `schemas/` — schema-level contracts.
- `compatibility/` — cross-version compatibility and migration rules.

A specification becomes stable only when explicitly declared stable; directory presence alone is not a stability promise.

# Security Policy

TRUYN is security-sensitive infrastructure. Please do not publish exploitable vulnerabilities in public issues.

## Reporting

Until a dedicated security contact/process is published, use GitHub private vulnerability reporting when available. Do not include private keys, credentials, production secrets, or personally identifying data in reports.

## Scope

Security work includes protocol integrity, node identity, cryptographic key handling, trustability manipulation, Sybil/collusion resistance, transport security, storage protection, adapter isolation, and supply-chain security.

## Status

TRUYN is pre-1.0 experimental software. Security guarantees will be documented per release and protocol version.

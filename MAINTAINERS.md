# TRUYN Maintainers

This file is the public roster of project governance roles. It records actual authority, not aspirational future seats.

See `GOVERNANCE.md` for role definitions and promotion/removal rules.

## Current governance phase

**Bootstrap / G1 governance contract defined.**

TRUYN does not yet have an independent multi-organization TSC and does not yet claim neutral legal stewardship.

## Founding Steward

- **InnMedia** — founding project steward during the bootstrap phase.

The Founding Steward currently performs the project-level approval functions that a future TSC will perform under the public governance process. This role is transitional and does not create a permanent right to control the protocol standard.

## Maintainers

No independent Maintainer roster is claimed in this file until appointments are explicitly recorded under the governance process.

Repository collaborators or employees are not automatically project Maintainers merely because they have GitHub permissions.

## Technical Steering Committee

**Not yet constituted.**

The roadmap target requires at least three independent organizations/constituencies and no single-organization voting majority before TRUYN claims multi-organization governance.

## Security Response Team

Security contacts and private vulnerability-reporting procedures are governed by `SECURITY.md`. Membership of an operational security response group may remain non-public when disclosure would create security risk; this does not create hidden normative protocol authority.

## Roster update rule

Changes to this file must correspond to an actual governance decision or factual role change. Do not add aspirational members, partner logos, advisors or organizations that have not accepted the stated governance responsibility.

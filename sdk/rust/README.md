# TRUYN Rust SDK

**Status:** optional secondary SDK track / repository scaffold.

Rust is a useful ecosystem target for systems and embedded/network tooling, but the required first-party SDK program before stable v1 is:

- JavaScript / TypeScript;
- Python;
- Go;
- Java;
- C# / .NET.

A Rust SDK may be implemented and published if maintained, and should reuse the same Agent Descriptor, protocol compatibility and conformance fixtures as the required SDKs.

Architecture: `../../docs/architecture/SDK_DEVELOPER_EXPERIENCE.md`.

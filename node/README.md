# TRUYN Node

The Node is the installable long-running network participant. Planned daemon name: `truynd`.

A Node owns runtime orchestration for identity, peer/network sessions, local storage, capability advertisements, request dispatch, object/state handling, trust evaluation, compute execution delegation, health and telemetry.

The Node is **not an AI model**. Models/agents connect through adapters, SDKs or local APIs.

Routine software updates must preserve node identity unless an explicit identity rotation/recovery operation occurs.

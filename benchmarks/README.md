# Benchmarks

TRUYN benchmark results must be reproducible and clearly distinguish measured results from derived arithmetic/examples.

Measurement areas:

- end-to-end latency and time-to-first-result;
- throughput and peer scale;
- bytes transferred and delta/object reuse ratio;
- AI input/output tokens per workflow;
- avoided duplicate inference calls;
- model/inference cost under published price assumptions;
- cache/object reuse;
- trust verification latency/cost;
- raw vs independent attestation scale;
- compute-near-data avoided transfer;
- failure/failover recovery;
- CPU/memory/storage overhead.

Core economic metric:

> useful, trustworthy machine cooperation per dollar, per second and per unit of compute.

No production performance claim belongs in README/Whitepaper until a benchmark artifact can reproduce it.
